# complyai demo

Static, browser-only build of the Agentic Compliance Auditor frontend (fictional fintech Northstar Payments) with recorded responses in place of the FastAPI backend. Review decisions and uploads live in memory for the browser session.

Rebuild: `bash demos/complyai/build.sh` (writes site/projects/complyai/app/). The fixtures in overlay/lib/fixtures.json were recorded from the real backend with `tools/record_fixtures.py <repo clone>`.
